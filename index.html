Robotics & Object-Oriented Programming

One-on-one or small group, from first principles through a working project you keep.

Robotics

1-ON-1 / GROUP

Hands-on robotics for beginners through intermediate builders — how sensors, actuators, and code work together as one system, taught the same way I build monitoring hardware.

  • Microcontroller basics: circuits, sensors, actuators
  • Reading sensor input and driving motors from code
  • Control logic: feedback loops and simple automation
  • Building a complete project from wiring to working demo

  • Designing clean class structures before writing code

FORMAT · weekly sessions, code-first, exam/coursework support included
